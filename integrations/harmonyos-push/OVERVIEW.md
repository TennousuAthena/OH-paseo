# 鸿蒙消息推送

将 Paseo 顶层会话的任务完成、待确认操作通过华为 Push Kit 发送至已启用通知的 OH-Paseo 手机或平板。锁屏只显示通用提示，点击后返回对应会话。前台默认不展示远程通知，测试通知可前台展示。

适用于 Mac/Linux 上的 Paseo 0.13–0.14。每台运行任务的主机需配置应用所属华为项目的服务账号，OH-Paseo 的“设置 → 通知”按主机启用。系统通知权限、含 Push Kit 权益的签名 Profile 和正确的数据处理地区均需生效。默认消息分类受华为日限额约束，工作提醒分类需要相应权益。

插件以 daemon 用户权限读取本机私有服务账号及设备绑定文件，并向华为发送设备令牌和通知路由 ID。服务账号私钥仅留在主机，不发送给客户端。它不读取对话内容。设备绑定在 48 小时未续期后失效，关闭通知会注销当前设备，离线注销在重连后重试。
