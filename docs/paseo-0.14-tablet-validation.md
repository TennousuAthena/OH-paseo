## 修复

- 重做触屏输入补丁，兼容上游新增的 `sendShortcut`，保留平板 Return 换行行为。
- 补齐 `isHarmonyApp` 与 `hasHarmonyScanner` 导出。旧快照包含这些手工修改，旧补丁集却没有，干净构建会失去系统返回和扫码能力；新增测试覆盖普通浏览器、鸿蒙 PC/平板能力及非 Web 运行时。
- 快照按本版本锁文件安装依赖，执行上游 postinstall，确认 bottom-sheet 的内部 provider 导出存在。
- 版本同步读取实际打包快照，修复此前读取参考工作树版本造成的混用风险。
- Web 导出写入 `ohpaseo-build.json`；跳过重建时校验版本、提交和补丁摘要，拒绝缺少记录或过期的导出。
