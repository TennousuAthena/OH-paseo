测试通过真实平板 ArkWeb 界面和独立 daemon 完成，文件编辑与 PTY 执行使用真实磁盘/进程。模型清单使用实际 0.15.4 实现，CLI 版本与模型发现结果受控；回复和权限事件使用上游确定性 provider，不调用真实 Claude/Codex 服务，也不代表模型账号权限或华为 Push Kit 云送达已经验证。上游测试 session 未实现动态 `setModel`，模型会话配置以新建会话验收。

未采集 0.15.4 安装前的应用内哈希，不能据此宣称升级前后三项原文完全一致；本轮摘要比较的范围是端到端测试前后、冷启动前后。私有脚本、截图和元数据保存在 `docs/evidence/paseo-0.15.4-tablet/`，不入库。正式 6767 daemon 未重启，原主机连接保留，平板继续保留 hdc 连接与已授权的 24 小时亮屏超时。

新增 Fable 5.2/Mythos 5.2 的清单由运行任务的 daemon 提供。要使用该清单，主机也需更新到包含此改动的 Paseo，并使用 Claude Code 2.1.321 或更新版本；Mythos 5.2 仅在 Claude Code 宣告可访问时出现。单独更新鸿蒙客户端不会升级主机软件或授予模型权限。

按用户要求，只验证本次改动及影响范围，不重复扫码、系统返回、横竖屏等未改动部分。
